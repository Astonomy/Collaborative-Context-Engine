# 开发登录与端口修复（2026-10-31）

## 根因与恢复

- `.env` 配置数据库为 WSL 本地 `localhost:5432/cce`。原有 PostgreSQL 容器停止时，
  使用开发 token 经 Vite `/api/session` 登录得到 500。启动已有数据库容器后，同一请求返回 200。
- 后续 3001 被 `collaborative-context-engine-api-1` Docker 容器占用，另起开发 API
  得到 `EADDRINUSE`。保留 Docker 服务，在未跟踪的根 `.env` 中配置 `CCE_API_PORT=3002`。
- 开发启动脚本先加载根 `.env`，确保 API 和 Vite 代理使用同一端口；已有进程环境变量优先。

503 `DEPENDENCY_UNAVAILABLE`，提示稍后重试并由管理员检查 PostgreSQL 和连接配置。
未知异常仍返回 500，提示重试及联系管理员。5xx 消息直接包含请求编号，以便页面用户反馈。
